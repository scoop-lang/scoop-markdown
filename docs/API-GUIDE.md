# Markdown API 导航

桌面应用 `markdown-editor` 可不带文件参数启动；新建、系统打开／保存面板、最近文件、多个文档窗口及未保存确认由应用管理，使用方式见[编辑器说明](../markdown-editor/README.md)。

此导航随库源码维护；完整用法见 [scoop.markdown](../scoop.markdown/README.md) 与 [scoop.ui.markdown](../scoop.ui.markdown/README.md)。

源码、预览与富文本 View／Host 自带按溢出显示的滚动条，借用各自的 ScrollState，支持拖动、轨道翻页和滚轮；正文输入区域使用系统 I 型鼠标光标。这些行为无需额外包裹 scrollArea；双栏仍使用 MarkdownEditorViewState 的 sourceScroll／richScroll 和 synchronizeScroll。

| 任务 | API 与用法 |
| --- | --- |
| Markdown 源文档、解析、事务与生成 | `scoop.markdown` 的 README 与 `examples/source`；`parseMarkdown`／`MarkdownDocument.parse` 显式解析；`MarkdownProfile.Editor` 开启公式、front matter 和脚注，`MarkdownExtension`／`mdBookDirectives()` 注册自定义语法；`parsed.region(range)` / `region.after(change)` / `region.parse()` （MarkdownRegion／ParsedMarkdownRegion，使用全局源码坐标）； `MarkdownSyntax.inlineContentAt(position)`；`syntax.textContent(sourceRange)` 提供 MarkdownTextContent，多块 replaceText／setStyle／edit／restore 返回 MarkdownTextEdit，含 source selection、显示 insertedRange 与 after 映射；粗体／斜体／删除线按块格式化并保留原子扩展，styleState 返回 Off／On／Mixed／Unavailable，profile 提供解析配置；批次 setStyle／setCode 保留新文字的 insertedRange；setCode／codeState 提供行内代码与跨块转换，replaceText 的 code: Boolean? 在规范化前决定输入模式；行内 setLink／removeLink／replaceImage 准备选区链接或原子图片事务，生成直接 URI，不修改共享定义、不读图像； `nodes()`／`parent(id)` 查询，`transform(parsed)` 修改结构；wrapBlockQuote／unwrapBlockQuote 增减引用层级，wrapBulletList／wrapOrderedList／wrapTaskList 将连续同级块包装为列表并保留正文；setFencedCode 将段落／标题的行内 Markdown 作为字面代码，默认 last=first，info 单行；setCodeInfo 修改完整单行代码信息，保留围栏正文，必要时转换缩进代码与冲突围栏；`snapshot.prepare(edit)`／`syntax.prepareTransform { ... }` 先准备 MarkdownChange，可解析其 after 再 `applyTo(document)` 发布；indentListItem／outdentListItem／unwrapListItem 调整列表层级，setBulletList／setOrderedList 显式转换并编号，保留正文和精确逆向；表格支持 insertTableColumn／removeTableColumn／setTableColumnAlignment，setTableCells 写入普通文字矩形并按需扩展，pasteTableTsv 支持带引号的 Tab／换行，整次修改可精确撤销。`inlineContent(id)` 提供段落／标题／单元格的显示文字，`replaceText`／`setStyle` 准备带源码差量与新选区的 `MarkdownInlineEdit`，用 `applyTo(document)` 发布；after 提供可继续输入的局部内容，nodes 可读取当前局部语法；空文件使用 root.id 取得位置 0 的空区域，change.mapBack 将新锚点映射到基线。`content.edit { ... }` 将多次语义操作准备成一次事务，restore 恢复同一区域的确切源码。`splitBlock(id, range)`／`joinBlocks(first, second)` 准备带结果光标的 MarkdownBlockEdit，拆分继承列表、任务与引用容器，合并要求同容器相邻段落／标题。UI 可交给同一 editor.apply。`syntax.exportMarkdown(sourceRange)` 导出独立语义片段，补齐样式、引用目标和脚注；`replaceMarkdown(sourceRange, markdown)` 准备 MarkdownFragmentEdit（change、源码 selection、局部 after），保留容器并处理脚注冲突，用 applyTo 一次发布，两个接口均使用源码 UTF-8 坐标。`markdownDocument`／`markdownText` 使用 receiver DSL 生成。`MarkdownProcessingSession`／`MarkdownProcessor` 配合应用 resolver 显式展开内容，`mdBookProcessor()` 支持 include，结果带来源映射与版本依赖。未安装的新库使用 path 依赖；解析不隐式读 include 或生成图片 |
| Markdown 扩展识别与源码索引 | `MarkdownProfile.nodeExtensions` 注册 `MarkdownNodeExtension`，匹配已有 Image／CodeBlock 等节点；新增语法仍用 extensions。`markdownCodeExtension` 与 `markdownImageExtension` 提供围栏语言和图片规则。`MarkdownSyntax.extensionIndex()`／`MarkdownInlineContent.extensionIndex()` 返回 snapshot 对应的索引，spans 保留原 node、name、Inline／Block form、完整 sourceRange、closed 和扩展 parent；at／intersect／forNode 按位置、范围和节点查询。图片引用定义仍保留自身映射，不混入使用点范围。UI 的 sourceExtensions／previewExtensions 分别索引原始与派生语法，`MarkdownParseOptions.presenters` 按名称注册 `MarkdownExtensionPresenter`，Inline／Block 方法分别选择 Native、Source 或 Image；`markdownImagePresenter`／`markdownNativePresenter`／`markdownSourcePresenter` 提供语义适配，注册覆盖同名默认。`MarkdownImagePresentation` 保留映射输入、info、attributes 与替代文字，`MarkdownImageKind.Extension(name)` 选择图像适配；自定义 profile 显式注册所需规则。用法见两库 README 和 UI 的 IMAGES.md |
| Markdown 多行块语法 | `MarkdownProfile.blockExtensions` 注册 `MarkdownBlockExtension`；start 接收当前容器内的一行，返回独立的 `MarkdownBlockStart`／`MarkdownBlockParser`。next 返回 Continue／Close／Stop，finish 接收完整映射文本并返回 `MarkdownBlockResult` 的 body 范围与属性。parser 管理空行、缩进、引用／列表前缀与容器边界；interruptsParagraph 默认 false，closedAtBoundary 默认 false。parseBody 开启后正文成为 Extension 的 Markdown 子节点，参加共享引用解析与扩展索引；每次出现的 parser 状态不可共享。既有 token 规则的 blocks 仍是整段落匹配。完整使用示例见文档 Cone 的 examples/source/tests/block_extensions.scoop，合同见 Markdown spec §9.3 |
| Markdown 编辑状态、源码与富文本 | [scoop.ui.markdown](../scoop.ui.markdown/README.md)、[IMAGES.md](../scoop.ui.markdown/IMAGES.md) 和 [markdown-editor](../markdown-editor/README.md)；`markdownEditor(viewState, controller)` 提供 Source／Wysiwyg／SideBySide，viewState 保留两侧焦点与滚动，支持右侧只读、分栏比例及源码锚点同步。光标进入扩展或点击源码入口时原位展开完整源码，Inline 保留同段文字，Block 按行虚拟化；离开、Done／无组合时 Escape 恢复显示。MarkdownRichHost.editSource／finishSource／sourceRegion 提供显式控制，共用原生输入区与历史。代码工具条有 Language / info、Apply、Copy code；临时损坏的语法仍能修复。`onSource` 可接管显式入口，`showSource(range)` 显式切换并聚焦完整源码起点，组合入口只通知一次正文变化。`markdownSourceEditor`／`markdownPreview`／`markdownRichEditor` 可独立使用，Host 支持自绘及借用 initialScroll。`MarkdownSourceRegion(editor, range)` 以全局 UTF-8 坐标跟随共享文档变化，传给 SourceInput／SourceHost／markdownSourceEditor 的 region 将排版、原生输入和键盘命令限定在该区间；调用方关闭 region，Reset 后 range 为 None。`MarkdownEditorState` 共享选区、事务、撤销和组合；SourceInput 提供局部源码 native 快照，RichInput 按行内显示映射连续输入。RichHost 复用预览虚拟化，活动段落／标题／单元格立即显示局部编辑；Enter 分段／列表延续，边界删除合并相邻段落，Tab／Shift-Tab 调整列表或导航表格，末格新增行、TSV 矩形粘贴和局部多行立即显示；跨块选择、剪切／粘贴／删除、整篇替换与输入法取消共用 MarkdownTextContent；MarkdownRichInput.content 的单段结构从 inlineContent 读取，表格网格和不同容器边界保留。RichInput.setStyle 对选区执行跨块格式事务，折叠位置控制后续输入，组合取消恢复原文；返回 true 时退休旧 native 连接。RichHost／viewState 的 blockState／executeBlock 接收 MarkdownBlockCommand；可选 markdownBlockToolbar 提供 Block／List／Table 菜单，Primary-0／1…6 转换段落／标题，支持引用、列表类型／层级、代码、分隔线与表格行列／对齐；InsertTable 的行数包含表头，菜单默认 3 × 3，禁止删除表头和最后一列，代码转换进入局部源码；状态读取已有投影，执行使用当前局部区域与一次共享历史。RichHost／viewState 提供 styleState、setStyle／toggleStyle；可选 markdownFormattingToolbar 沿用 ThemeSource，Primary-B／I／Shift-X 切换粗体／斜体／删除线，支持 Mixed，纯源码或只读禁用；连续格式键入与文字共用撤销。setCode／toggleCode／codeState 与 Primary-E 提供代码转换和后续输入，退出代码后换行保留。canEditTarget／beginTarget(Link 或 Image) 返回 MarkdownTargetDraft（label、destination、title、labelEditable、canRemove），applyTarget／removeTarget 只应用仍匹配文档和选区的草稿；工具栏有原生输入 Link／Image 模态面板，URI 由宿主提供，关闭恢复富文本焦点。默认 Copy/Cut 同时写所见 text/plain 和语义 text/markdown；富文本 Paste 按存在性优先 Markdown、HTML、普通文本，空表示不回退。Markdown 语义插入，HTML 经 importMarkdownHtml 转换，普通文本按字面处理；源码默认原样粘贴 Markdown／普通文本。Host／viewState.executeClipboard 接受 MarkdownClipboardCommand 的 CopyText、CopyMarkdown、PasteText、PasteMarkdown、PasteHtml、PasteTableTsv；PasteHtml 优先 HTML，缺失时把普通文本解释为 HTML，源码模式插入转换后的 Markdown；PasteText／TSV 只读普通文本，PasteMarkdown 不读 HTML。菜单调用无需保留输入面焦点，成功后返回活动栏；转换遵守当前 profile，共用历史与只读规则，TSV 只由显式命令处理。`MarkdownParseController` 借用 executor／proxy 合并后台解析、展开与显示投影；MarkdownParseOptions.codeHighlighter 默认使用 Prism 词法规则与 scoop.regex，可传自定义 MarkdownCodeHighlighter 或 None；MarkdownCodeSpan 使用代码 UTF-8 字节与 MarkdownCodeKind，提供器后台串行调用，未知语言／失败保留原文，未变化代码复用结果。sourceHighlights／previewHighlights 绑定各自 snapshot，独立源码 view／host 可传 highlights，过期范围不用于新源码，codeTheme 提供 Light／Dark 与自定义颜色；current 提供完整树，MarkdownRegion 提供匹配当前快照的局部结构，latest 可保留旧显示。语法扩展可在局部 owner 与后台线程调用，共用实例须不可变或同步；处理器／resolver 仍后台串行。measurement.sourceRevision 是实际显示版本，parsed 可仍是后台基线。`MarkdownImageController` 按可见请求共享图像，提供本地 PNG／JPEG、Mermaid CLI、MathJax＋rsvg-convert 适配；`MarkdownImageRenderer` 接收自定义扩展，外部工具由宿主预先配置 |
| Markdown 全文查找替换 | `scoop.markdown` 的 `snapshot.search(MarkdownSearchQuery)` 搜索原始源码，提供大小写／整词／正则规则；结果以 UTF-8 范围支持 count、索引、next 和 intersecting。prepareReplace／prepareReplaceAll 返回 MarkdownChange，applyTo 检查实际快照；template 支持 `$0`、`$1`、`${name}`、`$$`，全部替换只使用原匹配集合。`scoop.ui.markdown` 的 MarkdownSearchController(viewState, executor, proxy) 合并后台查询，markdownSearchBar 与 markdownEditor 的 search 参数接入原生字段、结果计数、可见范围高亮及 Primary-F／Alt-F／G；Enter／Shift-Enter 导航，组合结束后 Escape 返回活动栏。替换复用共享历史并遵守只读，查询字段历史独立；隐藏后正文修改不继续全文搜索。单独 View／Host 可传 searchResult，样式 searchMatch 设置颜色；结果不包含外部 include 派生正文 |
| Markdown 标题、大纲与位置导航 | `scoop.markdown` 的 `parsed.navigation()` 提供 MarkdownNavigation／MarkdownHeading、headings／headingAt、resolveLink 与 tableOfContents，绑定原始快照；snapshot.positionAt／lineColumn 使用零基物理行和 Unicode 标量列。Editor profile 默认启用 tableOfContentsDirective()，保存保留 [TOC]。`scoop.ui.markdown` 的 MarkdownNavigationController(viewState, parser) 提供 current／latest／activeHeading、goTo／goToLine／goToHeading／goToLink 及 goBack／goForward；已有位置随编辑映射，Reset 清空，不增加正文撤销项。markdownOutline 虚拟化标题，markdownNavigationBar 提供一基 line:column 字段及 Primary-L，markdownEditor 的 navigation 参数接入目录／内部链接历史。最终预览 TOC 包含扩展生成标题，来源映射回原指令；controller 由调用方关闭 |
| Markdown 编辑器折叠 | `scoop.ui.markdown` 的 MarkdownFoldingController(viewState, parser) 与 markdownEditor 的 folding 参数共享两栏折叠；独立 View／Host.update 也可传 folding，局部源码不折叠。MarkdownParsedDocument.sourceFolds 在后台建立 MarkdownFoldIndex，regions／at 返回带 snapshot、node、kind、range、header、hidden 的区域。标题／front matter 折叠预览与源码，代码围栏仅折叠源码；setCollapsed／toggleAt／collapseAll／expandAll 和 markdownFoldingToolbar 不改正文或撤销，展开父项保留子项状态。搜索／导航／程序化光标先展开目标，组合范围不可收起，边界删除先展开隐藏正文；显式跨区选区仍操作完整源码。高度树整段跳过隐藏行，过期区域和帧不能作用于新布局；控制器借用 editor／parser，调用方负责 close |
| 无 UI 的 HTML 导入 | `scoop.markdown.importMarkdownHtml(html, MarkdownHtmlImportOptions(...))` 返回 MarkdownHtmlImportResult 的 markdown、sourceRange、diagnostics；范围为原 HTML 的 UTF-8 字节，正式 StartFragment／EndFragment 注释对可选取剪贴板片段。profile 默认 Gfm，write 默认不加最终换行，baseUri 仅解析相对链接与图片，不读取资源或 HTML base。支持常见块、格式、列表、代码与普通矩形表格；未知元素、无法表示的编号／表格和 profile 禁用结构保留原 HTML 并诊断。已转换标签只保留对应语义属性，CSS 仅支持字重、斜体、删除线；不执行脚本或重建浏览器布局。已有文档用 replaceMarkdown／applyTo 准备并发布一次语义修改；示例见文档 Cone 的 examples/source/tests/html.scoop |
| Markdown 原生交互 | `MarkdownSourceOptions.interaction`／`MarkdownPreviewOptions.interaction` 接收 `MarkdownInteractionOptions`，配置原生上下文菜单、拖入／拖出、Touch／Pen、触摸滚动、回弹、系统滚动条和 SemanticProperties。`contextMenuItems` 可提供 `() -> NativeMenuContent`，在定位选区后追加菜单项及嵌套子菜单。`MarkdownEditorOptions.source`／`rich` 透传各自配置。Source／Preview／Rich Host 的 `showContextMenu()` 用当前聚焦文本面打开原生菜单。只读面保留复制／拖出／选择和滚动；可写面的拖入和无障碍修改复用共享历史；同文档移动合并为一次撤销。显示文本的 UTF-8 位置映射到源码，滚动条复用唯一 ScrollViewport 并独立发布无障碍范围。API 示例与行为边界见 [UI README](../scoop.ui.markdown/README.md)，实际操作见[交互验证](INTERACTIONS.md) |
