# Markdown 原生交互

源码编辑、只读预览与富文本共享 `MarkdownInteractionOptions`，默认使用 UI 库的原生菜单、输入归属、拖放、滚动视口和无障碍 provider。应用示例分别设置文本面的无障碍名称；完整编辑器还为所见即所得面追加格式菜单，并默认启用自动换行。

## 运行

从仓库根启动；请使用演示文稿的副本，便于自由编辑和保存：

```sh
cp examples/interactions.md /tmp/scoop-markdown-interactions.md
~/.scoop/bin/scoop --sysroot ~/.scoop run markdown-editor --release -- /tmp/scoop-markdown-interactions.md
~/.scoop/bin/scoop --sysroot ~/.scoop run scoop.ui.markdown/examples/source-editor --release -- /tmp/scoop-markdown-interactions.md
~/.scoop/bin/scoop --sysroot ~/.scoop run scoop.ui.markdown/examples/preview --release -- /tmp/scoop-markdown-interactions.md
```

基础库要求及预编译依赖的 `--cone-path` 用法见[根 README](../README.md)。macOS 窗口激活与原生输入建议使用[编辑器的 app 打包方式](../markdown-editor/README.md)。

## 人工操作

| 操作 | 预期 |
| --- | --- |
| 鼠标／触控板单击、双击、三击正文；双／三击后按住拖动，反向扩选；Shift 点击 | 单击定位、双击选词、三击选逻辑行；拖动按词／行扩选并保留方向，Shift 按字符扩选。格式与链接文字同样可选择，多击不打开链接 |
| 选中中文或格式文字，在选区内右键；再在别处右键 | 选区内保留方向，菜单项目随只读和历史变化；外部点按系统策略定位。Menu／Shift-F10 从键盘打开同一菜单 |
| 在所见即所得模式选中文字，使用顶端格式按钮和标题下拉；切换双栏活动窗格 | 工具栏提供常用格式和正文／1—6 级标题；仅在所见即所得模式或双栏的富文本窗格活动时显示，修改与撤销作用于当前选区 |
| 在所见即所得正文右键，选择粗体或“标题 → 2 级标题” | 原生菜单包含格式项及嵌套标题子菜单，操作可一次撤销；只读时禁用修改 |
| 在“显示”菜单切换“自动换行”，分别观察普通长段落、标题、列表、引用、长代码行与宽表格 | 默认开启；开启后按窗格宽度折行且无横向滚动条，关闭后普通文字和代码按自然宽度排版，超宽内容可横向滚动。段落和 Markdown 硬换行保留，双栏及右侧只读预览同时更新，文稿及撤销记录不变 |
| 在未修改的未命名空窗口中打开文件，再从有内容的窗口打开其他文件 | 优先复用符合条件的空窗口；已有内容、正在组合或曾修改后撤销到空白的文档不会被覆盖。重复打开同一文件激活原窗口 |
| 拖动选中的文字到同栏另一位置；按平台复制修饰键重复拖动；拖到另一文本应用 | 指针下显示按原抓取位置对齐的选区缩略图，换行间隙透明，离开窗口后仍随原生拖放移动。普通移动只需一次撤销，复制保留来源；库内富文本拖放保留格式，外部文本目标取得显示文字。取消拖动不删除内容 |
| 从另一文本应用拖入文字或 URL，悬停在文档上下边缘 | 可写面有插入光标，边缘自动滚动，放下后可一次撤销；只读预览拒绝写入 |
| 用触控板快速滚动至顶部／底部，拖动滚动条，按住轨道 | 惯性到达边界后立即回弹，同方向惯性尾段不反复打断回弹；选区／光标跟随显示内容。滑块及轨道只移动视口。静止后按系统偏好隐藏，靠近边缘或再次滚动时出现 |
| 系统切换“始终显示滚动条”和“减少动态效果” | 已打开窗口更新滚动条行为，减少动画时停止回弹／惯性动画 |
| 启用 VoiceOver，进入源码／正文／预览，选择文字或执行编辑、菜单及滚动动作 | 名称、内容、选区、只读状态与真实文本面一致；富文本读出显示文字；选择与替换映射到共享源码和撤销历史 |

有直接触屏或数位笔时，再检查短按定位、连续双／三击选词／选行、长按菜单、选区端点拖动和触摸滚动。macOS 触控板的双指滚动走滚轮／手势路径，不能据此宣称已实测直接 Touch／Pen。

2026-11-19 用户在本机复测确认：关闭／开启“自动换行”后，普通段落与代码块的长行／折行行为已一致，双栏及右侧只读下也正常。

## 自动覆盖

两个库的 release Cone 测试覆盖 UTF-8 选区映射、组合取消、预览显示文字与局部富文本投影、移动片段的格式和一次历史、滚动条参数及 RTL／Gutter 几何。`MarkdownViewportWindowTests` 继续验证三种宿主的实际滚动条像素、拖动／翻页、选区保持、系统光标和卸载；该测试显式选择 Static 滚动条，避免把操作系统的显示偏好固定成产品默认值。

`MarkdownInteractionWindowTests` 在本机原生窗口检查菜单命令、真实无障碍节点的内容与选区动作、只读拒绝，以及经过生产事件队列的 Touch 单击／双击和光标手柄跨行拖动。

`MarkdownPointerWindowTests` 使用 AppKit 的点击次数验证三个宿主的单击定位、双击选词、三击选行、按词／行正反向拖动、Shift 扩选，以及链接多击不会触发导航。

[编辑器应用窗口回归](../markdown-editor/tests-cones/window/README.md) 验证标题下拉与格式按钮的实际无障碍 Press、原生格式项与“标题”子菜单、修改和一次撤销、双栏焦点切换、最小窗口宽度下的控件边界，以及长代码和宽表格的折行与横向范围。另一用例检查原生窗口身份和标题、空文档复用、编辑后撤销到空白不复用、重复打开和读取失败。

普通文字换行修正后，本机窗口回归增加四份不含代码或表格的长文稿，分别覆盖段落、标题、引用和列表；确认关闭后真实排版高度减小且可横向滚动，双栏和右侧只读同样生效，重新开启后横向范围归零，源码、选区和历史保持。扩展后的窗口用例及 UI 库 189 项测试通过；本次修正未修改基础 UI。

2026-11-19 在本机 macOS arm64 完成 release 验证：文档库 295 项、UI 库 189 项和应用 8 项全部通过；源码输入、输入辅助、滚动条、原生菜单／无障碍／Touch、多击以及完整应用的两个窗口用例均通过。菜单和自动换行更新后重跑了 UI 库、应用、原生交互及多击用例。

整个工作区通过 release `check --tests`，三个 UI 示例均完成构建；完整编辑器已打包为 macOS app，并用新的演示副本启动。验证用的 UI 依赖包含下述两个基础库修复。

完整编辑器启动暴露了基础 UI 的 Resizable 缺陷：末尾面板的无效把手在无障碍初始化时读取不存在的相邻面板。修复位于 Scoop 的 `scoop.ui.component`，只在两个面板之间挂载把手；本仓库需消费包含该修复的配套组件产物。

Resizable 的单面板与多面板挂载／切换回归在 macOS、Windows MSVC UCRT 和 Linux X11 通过；Linux 使用独立 Xvfb 桌面，Wayland 桌面因锁屏不能完成呈现验收。本机完整编辑器三模式窗口回归通过。

触控板撞边后迟迟不回弹的问题来自基础 UI 的原生 momentum 处理：惯性尾段反复打断正在启动的回弹。修复后撞边立即开始弹簧释放，同方向尾段不再重启它，反向输入和双轴仍独立处理。本机 21 步原生 momentum 用例及其余 6 个 ScrollPan 窗口用例通过；Windows MSVC UCRT 与 Linux 均完成配套基础库编译和 19 项共享滚动逻辑测试。原生触控板时序只在本机验证，未扩展 Markdown 应用的多平台交互验收。

窗口回归还覆盖等值配置重建时的连续点按、程序修改选区后重新开始点按序列，以及中文段尾和格式文字的无障碍选区边界。真实硬件手感、跨应用系统拖动和屏幕阅读器朗读仍由人工操作确认；Touch／Pen 的自动用例是受控事件，不能代替实机结果。原始验证日志保存在仓库外。

### 原生拖动预览（2026-11-20）

macOS 的窗口测试在源码、所见即所得和只读预览三种文本面上读取原生拖动项，核对选区预览和自定义图像。Linux X11 上把源码和所见即所得选区分别拖入独立 GTK 应用，接收的 UTF-8 内容逐字节符合各自的导出规则。macOS、Linux 和 Windows 的 release 测试均覆盖透明底上的行内代码色、链接色、Unicode 选区移动和一次撤销，三个平台均完成了编辑器构建。

Windows 在 200% 缩放下从完整编辑器拖出同一段含粗体、链接和中文的文字。独立 OLE 进程在所见即所得模式收到显示文字，在源码模式收到包含 Markdown 标记的原文。两次收到的 Shell 位图均有透明背景，抓取点与按下位置一致。富文本位图保留了链接颜色。投放后编辑器正常退出。
